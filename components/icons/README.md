# Lucide Animated

Источник: https://lucide-animated.com, https://github.com/pqoqubbw/icons (MIT, см. LICENSE).

Компоненты palette, link, x взяты из публичного реестра. Обёртки div заменены на span для размещения внутри кнопок. У link исправлено имя начального состояния (normal), чтобы сброс анимации работал.

mail адаптирован из mail-check: анимация прорисовки перенесена на клапан конверта; галочка не добавлялась, геометрия исходной иконки контактов сохранена.

Запуск при наведении/фокусе всей кнопки и reduced-motion реализованы в ../portfolio/animated-icon.tsx.

Download взят из https://github.com/pqoqubbw/icons/blob/main/icons/download.tsx; обёртка span для кнопок. Анимация стрелки оригинальная, запуск и reduced-motion через AnimatedIcon.

ArrowLeft взят из https://github.com/pqoqubbw/icons/blob/main/icons/arrow-left.tsx; используется для ссылки «Назад» в резюме. Обёртка span, оригинальная анимация через AnimatedIcon.

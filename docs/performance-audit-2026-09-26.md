## Резерв следующих оптимизаций

На VPS уже включены HTTP/2, gzip для CSS/JS/JSON/SVG/текста и TLS session cache. Для HTML/RSC установлен no-cache. Для статических файлов нет явного длительного Cache-Control: повторные посещения могут выполнять лишние проверки свежести.

Следующий безопасный шаг при публикации — отдельная политика кеширования хешированных JS/CSS/шрифтов: public,max-age=31536000,immutable. Для неизменяемых по имени медиа и скачиваемого резюме такой срок применять нельзя: нужны версия URL или короткое кеширование/ревалидация. Конфигурация production не изменялась.

Lottie (~307КБ несжатого JS) и звуки (~162КБ) заметны в скриптах, но сейчас основной выигрыш дали медиа. Замену проигрывателя/формата звуков стоит делать отдельно с визуальной и звуковой проверкой; в эту правку не включено.

### Коррекция мобильной загрузки

После обратной связи с iPhone Safari: загрузка проектов начинается за 1000 px до области просмотра на сенсорных устройствах, воспроизведение по-прежнему ограничено ближайшей областью. Используется preload=auto. После готовности текущего персонажа последовательно подготавливаются изображения двух соседних стилей с низким приоритетом.

В восьми Safari MOV служебный блок moov перенесён в начало стандартной утилитой FFmpeg qt-faststart. Содержимое mdat и конфигурации hvcC/colr проверены побайтно относительно Git HEAD: кадры и прозрачность не перекодировались. URL версионированы. Сборка, TypeScript, проверки прокрутки всех проектов на desktop/mobile Chrome прошли. Физический iPhone Safari в этих проверках не использовался.

# Портфолио Данилы Плешакова

Адаптивная вёрстка актуальных макетов Paper. React, TypeScript, Vinext. Публичный сайт: https://ddedu375.github.io/.

## Запуск

```sh
npm install
npm run dev
```

Локальный адрес: http://localhost:3000. Проверки:

```sh
npm run build
npx tsc --noEmit
npx oxlint app components/portfolio lib
node --test tests/portfolio-state.test.mjs
```

Общий `npm run lint` также проверяет неизменённый каталог компонентов стартера и сообщает о его исходных ошибках. Проверка кода портфолио приведена отдельно выше. Эти сторонние компоненты не редактировались.

## Что работает

- Мобильная и десктопная компоновка, закреплённая шапка при прокрутке.
- Шесть секций-заглушек и якорная навигация между ними.
- Контакты: копирование email и Telegram, закрытие окна по Escape, нажатию вне окна или мобильному индикатору.
- Карусель персонажей: свайп, мышь, стрелки клавиатуры; выбранная карточка по центру.
- «Корпорат» доступен сразу; второй стиль открывается после стирания 50% бумажки в контактах, с уведомлением и конфетти. «Применить» выбирает персонажа.
- Светлая/тёмная тема. Тема, открытые и выбранный персонажи сохраняются локально.
- Резюме открывается в новой вкладке. Пока это страница-заглушка `/resume`.
- Горячие клавиши R / К для резюме и C / С для контактов.
- Отладка (включая опубликованный сайт): Ctrl+Shift+U показывает тост с эффектами; Ctrl+Shift+Backspace сбрасывает стили до «Корпората», сохраняя тему. В полях ввода сочетания не срабатывают.

## Где подставить материалы

`lib/portfolio.ts`: ссылка `profile.resumeUrl`, исходное видео `profile.defaultVideo`, видео и постеры персонажей. Сейчас все видео отсутствуют и показаны серыми блоками, как в макете. «Стиль 2» пока использует видео-заглушку.

Кейсы пока повторяют текст-заглушку из макета. Изображения и содержимое можно заменить в `components/portfolio/portfolio.tsx`; список якорей находится в `lib/portfolio.ts`.

Тёмная палитра подготовлена по светлому макету: отдельного тёмного макета нет. Системная строка телефона из Paper не входит в страницу сайта.

[Исходные макеты](https://app.paper.design/file/01M1V6P96QB64VKZPD50828CZC/2-0)

Иконки: hover-анимации [Lucide Animated](https://lucide-animated.com/) находятся в `components/icons` (лицензия и изменения рядом). Морфинг солнца/луны — [Morphicons](https://www.morphicons.com/), с учётом reduced motion. Hover срабатывает на всей кнопке и при клавиатурном фокусе.

Звуки четырёх кнопок главного блока: [Sound](https://github.com/mishanaer/sound), исходный assets/ui-sounds.js сохранён без изменений в lib/ui-sounds.js.

## Публикация

Исходники находятся в main, собранная статическая версия — в gh-pages. GitHub Pages публикует ветку gh-pages. Экспорт собирается командой `GITHUB_PAGES=true npm run build`; для обновления сайта содержимое dist/client нужно отправить в gh-pages. Обычный запуск разработки сохранён.
